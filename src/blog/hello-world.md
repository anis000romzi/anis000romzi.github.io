# Every post needs these 4 lines:
layout: post.html # wrap this post in src/_includes/post.html
tags: posts # put this post in the list on the Blogs page
title: Hello World
date: 2026-11-15
---

This is a sample post. Delete or replace it with your first real post.

To add a new post, copy this file in `src/blog/`, rename it, and change the
title, date and text. The file name becomes the address: `hello-world.md` is
published at `/blog/hello-world/`.
