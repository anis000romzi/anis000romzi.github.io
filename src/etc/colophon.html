This page is basically that inscription for this website: what it's built with, how it gets deployed, and why it looks the way it does.

How it's built

I kept it simple: plain HTML, CSS, and JavaScript, with Eleventy (11ty) as the static site generator and Nunjucks for templating. Blog posts are written in Markdown.

How it's deployed

Every push to master triggers a GitHub Actions workflow that installs dependencies, builds the site with Eleventy, and publishes the generated _site/ folder to GitHub Pages.

Design choices

I wanted an editorial feel with a warm color palette. The text is set in EB Garamond, loaded from Google Fonts, and the icons come from Font Awesome. I avoid the things that make a site feel bloated: generic design elements, heavy animations, walls of tech logos, and skill percentage bars. I want visitors to find what they're looking for as quickly and easily as possible.

Source code

The whole site is open source on GitHub. Feel free to look around, and if you find a bug or typo, I'd love to hear about it! Just open an issue.
